================================================================================
SIMAI FORMAT REFERENCE & GRAMMAR GUIDE
================================================================================
The .simai format (commonly stored inside `maidata.txt`) is the standard plain-text
chart representation used across the maimai simulation community.

--------------------------------------------------------------------------------
1. FILE METADATA HEADERS
--------------------------------------------------------------------------------
Files begin with key-value pairs marked with `&`:

&title=Garakuta Doll Play
&artist=t+pazolite
&first=0.55          <- Audio offset in seconds before the first beat
&des=ChartCreator    <- Chart designer name
&lv_1=4              <- Easy
&lv_2=7              <- Basic
&lv_3=9+             <- Advanced
&lv_4=12             <- Expert
&lv_5=14+            <- Master
&lv_6=14+            <- Re:Master (if present)
&inote_1=...         <- Chart content for Easy
...
&inote_5=...         <- Chart content for Master (simai string)

--------------------------------------------------------------------------------
2. PHYSICAL GEOMETRY (BUTTONS & SENSORS)
--------------------------------------------------------------------------------
The arcade cabinet has 8 perimeter buttons indexed clockwise starting at 10 o'clock:

            [8]       [1]
       [7]                 [2]
                 [C]
       [6]                 [3]
            [5]       [4]

* Perimeter buttons: 1, 2, 3, 4, 5, 6, 7, 8
* Coordinates (unit circle, r = 1.0):
  theta_k = (pi / 2) - (k - 1) * (pi / 4)
  x_k = cos(theta_k)
  y_k = sin(theta_k)

Touch Sensor Zones (DX version):
* Center: C, C1, C2
* Inner Ring / Screen Regions: A1-A8, B1-B8, D1-D8, E1-E8

--------------------------------------------------------------------------------
3. TIMING & STEP DIVISION
--------------------------------------------------------------------------------
Timing is measure-relative and modified using parenthetical and brace tags:

* BPM Changes: `(180)` sets the current BPM to 180.
* Time Subdivision: `{4}` means each comma `,` represents a 1/4 note (quarter beat).
  - `{4}`  = 4th notes (1 beat per comma)
  - `{8}`  = 8th notes (0.5 beats per comma)
  - `{16}` = 16th notes (0.25 beats per comma)
  - `{24}` = 24th notes (triplets)
* Millisecond calculation per comma:
  delta_t_ms = (60000.0 / current_bpm) * (4.0 / current_subdivision)

* Measure/Step Separator: `,` (comma advances the timeline by the current subdivision)
* Simultaneous separator: `/` (fires notes at the exact same timestamp)
  Example: `1/5,` -> Hits button 1 and 5 simultaneously, then advances 1 subdivision.

--------------------------------------------------------------------------------
4. NOTE TYPES & SYNTAX
--------------------------------------------------------------------------------

A. TAP NOTES
   Syntax: `[1-8]`
   Example: `1,2,3,4,` -> Taps around buttons 1, 2, 3, and 4.
   Special:
   - `b` suffix = BREAK note (e.g., `1b`) -> ignore for now
   - `x` suffix = EX note (cannot produce Good/Great, only Perfect or Miss) -> ignore for now

B. HOLD NOTES
   Syntax: `[button]h[[wait:]duration]`
   Example: `1h[4:1],` -> Hold on button 1 lasting 1 beat under 4th subdivision.
   If only one value is provided: `1h[2]` -> Lasts for a half-note.

C. TOUCH NOTES
   Syntax: `[SensorArea]`
   Example: `C,` (Tap center touch screen)
            `B1,` (Tap sensor zone B1)
            `Ch[4:1],` (Touch hold in center)
            `Cf,` (Hanabi / Firework touch note)

D. SLIDE NOTES
   Syntax: `[start][shape][end][[wait:]duration]`
   The first number in brackets is the wait time before the star sweeps (usually 4ths).
   The second number is the duration of the sweep itself.
   
   Example: `1-5[4:1],`
   - Star tap appears on button 1.
   - Waits 1 beat.
   - Sweeps across the diameter to button 5 over 1 beat.

--------------------------------------------------------------------------------
5. SLIDE SHAPE OPERATORS
--------------------------------------------------------------------------------
- `-`  : Straight line / diameter (e.g., `1-5`)
- `^`  : Circumference arc (closest direction, e.g., `1^3`)
- `<`  : Circumference arc counter-clockwise (e.g., `1<5`)
- `>`  : Circumference arc clockwise (e.g., `1>5`)
- `v`  : V-shape to center and out (e.g., `1v3` goes 1 -> Center -> 3)
- `p`  : Curve / loop traversing the perimeter (clockwise U-turn)
- `q`  : Curve / loop traversing the perimeter (counter-clockwise U-turn)
- `s`  : S-curve through the cabinet
- `z`  : Mirror S-curve (Z-curve)
- `pp` : Wide circle sweep clockwise
- `qq` : Wide circle sweep counter-clockwise
- `w`  : Fan / Wiper shape (touch screen sweep)

--------------------------------------------------------------------------------
6. COMPLETE CONCRETE EXAMPLE
--------------------------------------------------------------------------------
&title=Sample Chart
&artist=Artist Name
&first=1.0
&lv_5=13
&inote_5=
(150){4}
1,2,3,4,
{8}
5,6,7,8,1/5,
{4}
1-5[4:1],8,7,6,
E
